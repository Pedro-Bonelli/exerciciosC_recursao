# Exercícios de recursão em C

Coleção de programas curtos para praticar recursão em C. Os arquivos `rec01.c` a `rec34.c` representam exercícios separados.

## Estrutura

- Arquivos `.c`: exercícios independentes (ou o programa indicado acima).
- Pastas `Lista_Exercicios/`, `Testes/` ou `output/`, quando presentes: organização dos códigos e artefatos.

## Como executar

Requisito: GCC configurado no terminal.

```bash
git clone https://github.com/Pedro-Bonelli/exerciciosC_recursao.git
cd exerciciosC_recursao
gcc rec01.c -o programa
./programa
```

No PowerShell do Windows, execute `./programa.exe` (ou `.\programa.exe`). Cada arquivo `.c` é um exercício independente, salvo indicação no próprio código.

## Observações

Leia e execute os arquivos individualmente; a numeração não é contínua.
